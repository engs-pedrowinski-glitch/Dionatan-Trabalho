O que é o Grid?

O CSS Grid é um layout em duas dimensões: ele trabalha com linhas e colunas ao mesmo tempo. Enquanto o Flexbox organiza em uma linha OU uma coluna, o Grid divide o contêiner como se fosse uma tabela, e nós escolhemos em qual célula cada elemento vai ficar.

Alguns nomes que vamos usar:

  • Grid container — o elemento pai, que recebe display: grid;;
  • Grid items — os filhos diretos do contêiner;
  • Linhas (rows) e colunas (columns) — as divisões horizontais e verticais do grid;
  • Célula — o encontro de uma linha com uma coluna;
  • Gap — o espaço entre as linhas e as colunas.
.container {
  display: grid;
}

Só com o display: grid nada muda de verdade, porque o grid começa com uma coluna só e os itens ficam um embaixo do outro. O trabalho está em dizer quantas colunas e linhas queremos. Nos exemplos desta página todos os contêineres têm gap: 10px para as caixas não ficarem coladas (o gap tem uma seção só dele mais para frente).

Criando colunas e linhas

Usamos grid-template-columns para criar as colunas, e cada valor é a largura de uma coluna. Já o grid-template-rows faz o mesmo para a altura das linhas.

grid-template-columns: 100px 100px 100px — são 3 colunas, e como temos 6 itens o grid criou 2 linhas sozinho.

Os itens vão sendo colocados da esquerda para a direita e de cima para baixo, na ordem do HTML, e quando acaba uma linha o grid passa para a próxima.

A unidade fr e o repeat()

Usar só px deixa o layout travado. A unidade fr (fração) divide o espaço livre do contêiner. Em 1fr 2fr 1fr o espaço é dividido em 4 partes: a coluna do meio fica com 2 e as outras duas com 1 cada.

gap

O gap define o espaço entre as linhas e as colunas, sem precisar de margin nos itens.

  • row-gap — espaço entre as linhas;
  • column-gap — espaço entre as colunas;
  • gap — atalho. Com um valor (gap: 20px;) vale para os dois, com dois valores é linha e depois coluna.

Aqui são 10px entre as linhas e 40px entre as colunas:

Posicionando itens: grid-column e grid-row

As linhas que dividem o grid são numeradas a partir do 1. Um grid com 3 colunas tem 4 linhas verticais (1, 2, 3 e 4), e um item pode ocupar várias células dizendo em qual linha ele começa e em qual termina.

No exemplo, o A (laranja) ocupa duas colunas e o B (verde) ocupa duas linhas:

A
B

4

.item-a {
  grid-column: 1 / 3;   /* da linha 1 até a linha 3 = 2 colunas */
}

.item-b {
  grid-column: 3;
  grid-row: 1 / 3;      /* da linha 1 até a linha 3 = 2 linhas */
}

Outra forma é o span: grid-column: span 2; quer dizer "ocupe 2 colunas a partir de onde você estiver". E se usarmos grid-column: 1 / -1;, o item ocupa todas as colunas, porque o -1 é a última linha.

grid-template-areas

Outra forma de montar o layout é dar nome para as regiões. Cada item recebe um nome com grid-area e o contêiner desenha o layout com grid-template-areas, como se fosse um desenho feito com texto. É muito usado para a estrutura de uma página.

topo
menu
conteúdo
rodapé
.pagina {
  display: grid;
  grid-template-columns: 150px 1fr;
  grid-template-rows: 50px 120px 50px;
  grid-template-areas:
    "topo topo"
    "menu conteudo"
    "rodape rodape";
}

.topo     { grid-area: topo; }
.menu     { grid-area: menu; }
.conteudo { grid-area: conteudo; }
.rodape   { grid-area: rodape; }

Cada linha de texto é uma linha do grid, e repetir o nome faz a região ocupar várias colunas (aqui o topo e o rodape ocupam as duas). A vantagem é que, para mudar o layout no celular, basta reescrever o desenho dentro de um @media.

Alinhamento no Grid

No Grid o alinhamento também tem duas direções, mas aqui existe uma diferença importante: algumas propriedades alinham o item dentro da sua célula e outras alinham o grid dentro do contêiner.

  • justify-items — alinha os itens na horizontal, dentro da célula;
  • align-items — alinha os itens na vertical, dentro da célula;
  • place-items — atalho dos dois (place-items: center; centraliza);
  • justify-content e align-content — alinham o grid inteiro quando ele é menor que o contêiner.

Grid responsivo com auto-fit e minmax()

Dá para criar um grid que se ajusta sozinho ao tamanho da tela, sem precisar de @media. Para isso juntamos o repeat() com auto-fit e o minmax(): 

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 10px;
}
  • minmax(200px, 1fr) — cada coluna tem no mínimo 200px e no máximo 1fr;
  • auto-fit — cria quantas colunas couberem na largura disponível.

Grid ou Flexbox?

Os dois resolvem problemas diferentes, e dá para usar os dois juntos.

Flexbox

Uma dimensão: linha ou coluna.

O conteúdo dos itens é que define o tamanho.

Bom para menus, botões lado a lado e alinhar coisas dentro de um componente.

Grid

Duas dimensões: linhas e colunas.

Primeiro desenhamos o layout, depois colocamos os itens nele.

Bom para a estrutura da página, galerias e qualquer coisa que precise alinhar em linhas e colunas.

Um jeito comum de usar: Grid para a estrutura geral da página e Flexbox dentro de cada bloco (por exemplo, o menu dentro do topo).

Atividade Prática

Crie uma página que contenha:

  • Um grid de 3 colunas iguais com repeat(3, 1fr) e 6 caixas dentro;
  • Uma das caixas ocupando 2 colunas com grid-column: span 2;;
  • Um layout de página com topo, menu, conteúdo e rodapé usando grid-template-areas;
  • Uma galeria com repeat(auto-fit, minmax(200px, 1fr)), que muda o número de colunas ao diminuir a janela.

Depois compare com o que foi feito no Flexbox e pense em qual dos dois foi mais prático para cada situação.
