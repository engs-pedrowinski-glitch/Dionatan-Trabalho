O que é o Flexbox?

O Flexbox é um jeito de organizar elementos em uma dimensão só: ou em linha, ou em coluna. Ele cuida do espaço entre os itens e do alinhamento, sem precisar de float ou position.

Para usar, precisamos de duas coisas:

  • Contêiner flex — o elemento pai, que recebe display: flex;;
  • Itens flex — os filhos diretos do contêiner (os netos não contam).
1
2
3
.container {
  display: flex;
}

Só com isso, os filhos (que eram elementos div, um embaixo do outro) passam a ficar lado a lado. Nos exemplos desta página todos os contêineres também têm gap: 10px, só para as caixas não ficarem coladas. Vamos ver o gap com calma mais para frente.

Eixo principal e eixo cruzado

O Flexbox trabalha com dois eixos, e entender isso ajuda muito a lembrar das propriedades:

  • Eixo principal (main axis) — a direção em que os itens são colocados. Por padrão é a horizontal;
  • Eixo cruzado (cross axis) — fica de lado em relação ao principal. Por padrão é a vertical.

Se mudarmos a direção para column, os eixos trocam de lugar: o principal vira vertical e o cruzado vira horizontal. É por isso que o justify-content nem sempre alinha na horizontal.

flex-direction

Define a direção do eixo principal, ou seja, para onde os itens vão.

  • row — padrão, da esquerda para a direita;
  • row-reverse — da direita para a esquerda;
  • column — de cima para baixo;
  • column-reverse — de baixo para cima.

flex-direction: row

justify-content

Alinha os itens no eixo principal e decide o que fazer com o espaço que sobrou no contêiner. É a propriedade que usamos para centralizar na aula de Alinhamento.

  • flex-start — itens no começo (padrão);
  • center — itens no centro;
  • flex-end — itens no fim;
  • space-between — espaço entre os itens, sem sobrar nas pontas;
  • space-around — espaço ao redor de cada item (nas pontas fica a metade);
  • space-evenly — o mesmo espaço entre todos, inclusive nas pontas.

align-items

Alinha os itens no eixo cruzado (na vertical, quando a direção é row). Para ver o efeito, o contêiner precisa ser mais alto que os itens. Aqui usei height: 130px.

  • stretch — padrão, estica os itens até a altura do contêiner (se eles não tiverem height);
  • flex-start — itens no topo;
  • center — itens no meio;
  • flex-end — itens embaixo;
  • baseline — alinha pela linha de base do texto.

flex-wrap e gap

Por padrão o Flexbox tenta colocar tudo na mesma linha, e se os itens não cabem, eles encolhem. Com o flex-wrap a gente permite que eles quebrem para a linha de baixo.

  • nowrap — padrão, tudo na mesma linha;
  • wrap — quebra para a próxima linha quando não cabe;
  • wrap-reverse — quebra, mas as linhas vão para cima.

O gap é o espaço entre os itens, e dá para usar sem mexer em margin. Podemos passar um valor só (gap: 10px;) ou dois, linha e coluna (gap: 20px 10px;). 

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

Dois extras: o atalho flex-flow: row wrap; junta flex-direction e flex-wrap, e quando existem várias linhas o align-content controla o espaço entre elas (funciona igual ao justify-content, só que no eixo cruzado).

flex-grow, flex-shrink e flex-basis

Até aqui mexemos no contêiner. Agora vamos mexer nos itens, para controlar o tamanho de cada um:

  • flex-grow — quanto o item cresce para ocupar o espaço que sobrou. O padrão é 0 (não cresce). É uma proporção: quem tem 2 cresce o dobro de quem tem 1;
  • flex-shrink — quanto o item encolhe quando falta espaço. O padrão é 1;
  • flex-basis — o tamanho inicial do item no eixo principal, antes de crescer ou encolher. O padrão é auto (usa o width).

flex-grow: os três itens começam com 100px, mas só dois crescem

grow: 1
grow: 2
grow: 0

Os três atributos podem ser escritos juntos no atalho flex: grow shrink basis;. O mais usado é o flex: 1;, que faz todos os itens dividirem o espaço igualmente:

flex: 1
flex: 1
flex: 1

Outro uso comum: uma coluna lateral com tamanho fixo e um conteúdo que ocupa o resto da largura.

flex: 0 0 150px
flex: 1
.lateral {
  flex: 0 0 150px;  /* não cresce, não encolhe, 150px */
}

.principal {
  flex: 1;          /* ocupa o que sobrar */
}

align-self e order

Essas duas também são aplicadas nos itens, e servem para tratar um item de um jeito diferente dos outros.

O align-self funciona como o align-items, mas vale só para aquele item. No exemplo o contêiner tem align-items: flex-start, e os itens laranjas mudaram sozinhos:

1
2
3
.item2 {
  align-self: center;
}

.item3 {
  align-self: flex-end;
}

O order muda a ordem em que os itens aparecem, sem mexer no HTML. O padrão é 0, e quanto menor o número, mais cedo o item aparece. Aqui o item 3 está com order: -1:

2
3
4

Cuidado: o order só muda o visual. Quem navega pelo teclado (tecla Tab) continua seguindo a ordem do HTML.

Flexbox na prática

Onde o Flexbox aparece de verdade? Praticamente em todo site. Dois exemplos clássicos:

1. Menu de navegação — logo de um lado, links do outro (space-between) e tudo alinhado ao centro na vertical.

MeuSite
  • Início
  • Sobre
  • Contato
.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.menu ul {
  display: flex;   /* flex dentro de flex */
  gap: 20px;
}

2. Cartões que quebram de linha — cada um começa com 250px, cresce para ocupar o espaço e quebra quando não cabe.

Cartão 1

flex: 1 1 250px

Cartão 2

flex: 1 1 250px

Cartão 3

flex: 1 1 250px

Cartão 4

flex: 1 1 250px

Cartão 5

flex: 1 1 250px

.cartoes {
  display: flex;
  flex-wrap: wrap;
  gap: 15px;
}

.cartao {
  flex: 1 1 250px;
}

Repare que os últimos cartões ficaram maiores que os de cima, porque o Flexbox só olha uma linha de cada vez. Quando queremos que tudo fique alinhado também em colunas, o melhor é usar o Grid.

O style.css deste site também usa Flexbox: o body está com display: flex e flex-direction: column, por isso o cabeçalho, o conteúdo e o rodapé ficam empilhados e centralizados.

Atividade Prática

Crie uma página que contenha:

  • Um menu com o logo à esquerda e três links à direita, usando justify-content: space-between;;
  • Uma linha com 3 caixas de tamanhos iguais usando flex: 1;;
  • Uma lateral de 200px e um conteúdo que ocupa o resto da largura;
  • Uma caixa centralizada na horizontal e na vertical dentro de um contêiner com height: 300px;.

Depois, troque o flex-direction para column e veja o que acontece com o justify-content e com o align-items.
